# Release notes

## v1.0.0 — 2026-08-13

This is the first archival release of the ReFrame experimental artifact.

It contains:

- the implementation of all eleven experimental conditions;
- the locked Python 3.12 environment and regression tests;
- all 88,000 records from the main held-out experiment;
- sensitivity, planner-transfer, information-barrier, repair-multiplicity, and
  classifier audits;
- derived CSV, JSON, LaTeX, PDF, and PNG outputs; and
- GitHub and Zenodo citation metadata.
